# Quick Start Guide

## Open the Tracker

**Windows:**
- Double-click `launch.bat`
- OR double-click `index.html`

**Mac/Linux:**
- Open `index.html` in your browser

## First Time Setup

When you first open the tracker, it will automatically load with:
- ✅ All discovered/implemented features documented
- 📋 Todo items for missing features with implementation plans
- 📚 Complete wiki documentation

## Main Views

### 1. Dashboard
- See overall project progress
- View completion stats by category
- Check recent updates

### 2. Todo List
- All tasks organized by category
- Filter by status (todo, in-progress, completed)
- Filter by priority (critical, high, medium, low)
- Click task title to edit
- Check box to mark complete

### 3. Wiki / Docs
- Complete documentation for all systems
- Search functionality
- Click topics in sidebar to view

### 4. Roadmap
- Development phases
- Visual progress timeline

## Key Features

### Categories

- 🟢 **Rendering** - Graphics, sprites, cameras
- 🔵 **Input** - Keyboard, mouse, gamepad
- 🟠 **Audio** - Sound playback, music
- 🟣 **Physics** - Box2D integration
- 🔴 **Networking** - Multiplayer features
- 🎀 **Editor** - Development tools

### Creating Tasks

1. Click "+ New Task" button
2. Fill in:
   - Title
   - Category
   - Priority
   - Description
   - Implementation notes (technical details)
   - Subtasks
3. Save

### Exporting Data

Click "Export Data" button to download a JSON backup.
This is git-friendly and can be shared with team members.

### Importing Data

Click "Import Data" to load a previously exported file.

## Tips

- Data auto-saves to browser localStorage
- Export regularly for backups
- Use the search in Wiki view to find documentation quickly
- Mark tasks as "in-progress" when you start working on them
- Add detailed implementation notes to help future developers
